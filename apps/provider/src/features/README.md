# Provider Features Directory (`src/features`)

## Planned Provider Modules
- `dispatch/`: Real-time job acceptance/rejection, route guidance, on-scene status transitions.
- `inventory/`: Spare parts availability, equipment checklists (tow cable, battery booster, patch kits).
- `earnings/`: Daily/weekly payout summaries, job history, performance metrics.
- `onboarding/`: Mechanic verification, trade certifications, service vehicle registration.
