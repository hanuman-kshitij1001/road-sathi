# Admin Features Directory (`src/features`)

## Planned Operations Modules
- `dispatch-monitor/`: Live map bird-eye view of all active assistance emergencies, response times, and unassigned requests.
- `provider-verification/`: Document approvals, background checks, license verification for onboarding mechanics.
- `tariff-management/`: Dynamic pricing rules, night emergency surcharges, base distance pricing matrices.
- `incident-management/`: Escalations, disputed jobs, refund issuance, customer safety interventions.
