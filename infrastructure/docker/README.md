# Docker Infrastructure (`infrastructure/docker`)

## Purpose
Container definitions for all applications and microservices in the Road-Sathi ecosystem.

## Services
- `api.Dockerfile`: Production container for Core REST API.
- `ai.Dockerfile`: Isolated container for AI / ML inference and pipeline services.
- `web.Dockerfile`: User web application container.
- `provider.Dockerfile`: Partner/mechanic portal container.
- `admin.Dockerfile`: Backoffice administration portal container.
